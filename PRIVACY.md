# Privacy and network boundaries

This package does not collect analytics, store input, log message content,
read wallet keys, or access environment secrets. Your public Sentinel ID is
administrator configuration, not a model-selected argument.

An explicit Guard check sends the current text over HTTPS to the public
Heisto Guard API. An explicit evidence action fetches public records through
Heisto MCP. The plugin does not send text on import or registration and does
not automatically scan prior memory, tool results or attachments.

Do not submit secrets or personal/sensitive information. Network and service
providers may process request metadata, including IP addresses, and may retain
operational records under their policies. This is not a zero-retention promise.
Your ElizaOS host, model provider and chat transport may retain messages
independently, even when this package performs no local storage.

Place the gate before your own persistence and model calls. This cannot delete
copies already stored by an upstream chat platform.

Public testing evidence is not an ownership check or an audit. Contact
support@heisto.xyz for privacy questions.
